# 🌤️ Wetter-App

Eine kleine Wetter-App für Anfänger: Stadt eingeben → aktuelles Wetter sehen.

## Technik
- **HTML** – Aufbau der Seite
- **CSS** – Aussehen
- **JavaScript** – Logik (Wetter abfragen)
- **[Open-Meteo API](https://open-meteo.com/)** – kostenlose Wetterdaten, kein API-Key nötig

## Lernziele
- [ ] Git & GitHub benutzen
- [ ] Eine API mit `fetch()` abfragen
- [ ] Claude **Agents** (Designer, Builder, Reviewer)
- [ ] Eigene **Skills** schreiben
- [ ] **Connectors** (GitHub) verwenden

## Starten
Einfach `index.html` im Browser öffnen.
